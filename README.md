# 💬 Live Chat App (React + Vite)

A real-time live chat application built with **React (Vite)**.  
It provides a modern, responsive UI for seamless chatting.

---

## 🚀 Live Preview
👉 [Live Chat App](https://newlivechat.vercel.app/)

---

## 📦 Features
- Real-time chat interface
- Responsive and clean design
- React components with state management
- Easy to extend with authentication or backend API

---

## 🛠 Tech Stack
- React + Vite
- TailwindCSS (for styling)
- React Router (for navigation)

---

## ⚙️ Setup & Run

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/newlivechat.git
   cd newlivechat
